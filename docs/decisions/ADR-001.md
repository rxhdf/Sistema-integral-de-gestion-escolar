# ADR-001: Expediente académico como tabla separada de Alumno

**Estado:** Aceptado
**Fecha:** 2026-07-29

## Contexto

El modelo conceptual original propone `EXPEDIENTE_PERSONAL`,
`EXPEDIENTE_ACADEMICO` y `EXPEDIENTE_ESCOLAR` como tablas 1:1 con `ALUMNO`.
Se evaluó consolidarlas como columnas directas de `ALUMNO`.

## Decisión

Se mantiene `Expediente_Academico` como tabla separada de `Alumno`.
`Expediente_Personal` y `Expediente_Escolar` quedan **fuera del alcance del
MVP** (ver ADR-002 sobre alcance reducido).

## Razón

Separar el expediente permite aplicar políticas RLS por tabla completa (un
docente nunca tiene ni la posibilidad de hacer join a datos que no le
corresponden) en vez de depender de RLS a nivel de columna, que es más
compleja y propensa a error en PostgreSQL.

## Alternativas descartadas

- **Columnas en `Alumno`**: descartado porque dificulta el control de acceso
  granular por rol — mezclaría datos operativos (nombre, matrícula) con
  datos de rendimiento académico (`promedio_actual`, `situacion_academica`)
  en la misma tabla, complicando las políticas RLS.
