# ADR-004: Directivo/Admin pueden modificar calificaciones ya capturadas

**Estado:** Aceptado
**Fecha:** 2026-07-29

## Contexto

Según la matriz RBAC (Nivel 1), el docente tiene C-R-U sobre `Calificacion`
solo dentro de sus propios `Grupo_Asignatura`. Se definió si `directivo`/
`admin` deben tener acceso de solo lectura, o también de escritura/
corrección sobre calificaciones ya capturadas por un docente.

## Decisión

`Directivo` y `Admin` tienen permiso de `UPDATE` sobre `Calificacion`,
además de `R`, con el mismo alcance de todo el plantel. Pueden corregir una
calificación ya capturada por cualquier docente.

## Razón

Confirmado como requerimiento de negocio: casos de disputa o error de
captura requieren que un directivo pueda corregir sin depender
exclusivamente del docente original (que puede no estar disponible o ya no
estar asignado al grupo).

## Alternativas descartadas

- **Directivo solo con `R`, corrección vía endpoint especial de
  "corrección administrativa"**: descartado — el negocio confirmó que la
  corrección directa por directivo es el flujo esperado, sin necesidad de
  un endpoint separado.

## Consecuencias

- La tabla/mecanismo de auditoría de `Calificacion` debe distinguir
  explícitamente entre `id_personal_capturo` (docente original) e
  `id_personal_modifico` (quién hizo el último cambio), para preservar
  trazabilidad de quién capturó vs. quién corrigió.
- No se exige `motivo_correccion` obligatorio en el MVP, para no bloquear
  el flujo. Si en producción se detectan correcciones frecuentes sin
  contexto suficiente, agregar el campo en iteración posterior.
